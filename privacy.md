This is the personal academic website of Pietro Ferrara. It is a static website hosted on [GitHub Pages](https://pages.github.com/), and it does not collect personal data, host advertisements, or profile its visitors.

## Traffic measurement

To understand how many people visit this website and which pages they read, this site uses **Google Analytics 4**, a web analytics service provided by Google. Google Analytics collects aggregate information about visits — such as the pages viewed, the type of browser and device, and the approximate geographic area derived from the IP address — through cookies and similar identifiers. This information is processed by Google on my behalf and is used exclusively to produce aggregate statistics about the traffic of this website. IP addresses are not stored by Google Analytics 4.

If your browser sends the "Do Not Track" signal, tracking on this website is automatically disabled. You can also opt out of Google Analytics on all websites by installing the [Google Analytics opt-out browser add-on](https://tools.google.com/dlpage/gaoptout).

For more details on how Google processes data, see [How Google uses information from sites or apps that use our services](https://policies.google.com/technologies/partner-sites).

## Hosting

This website is served by GitHub Pages. GitHub may collect technical information such as IP addresses in its server logs for security and operational purposes; see the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement).
